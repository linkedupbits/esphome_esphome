Most of the code in this integration is based on the VL53L1X library
by Pololu (Pololu Corporation), which in turn is based on the VL53L1X
API from ST. The code has been adapted to work with ESPHome's i2c APIs.

The offset/crosstalk calibration and region-of-interest (ROI) configuration
logic was additionally verified against ST's own public VL53L1X Ultra Lite
Driver (ULD) API, as published in ST's official Arduino library
(https://github.com/stm32duino/VL53L1X, accessed 9th August 2026) and
cross-referenced against SparkFun's Arduino library
(https://github.com/sparkfun/SparkFun_VL53L1X_Arduino_Library, accessed 9th
August 2026), which vendors the same ST ULD API source. Both are licensed
BSD 3-clause by STMicroelectronics for the vendored ULD API portions;
SparkFun's own wrapper code (not used here) is separately MIT-licensed,
copyright SparkFun Electronics.
